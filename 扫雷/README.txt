扫雷游戏
========

运行方法
--------
双击“扫雷.exe”即可开始游戏。程序会打开一个独立的浏览器应用窗口；如果系统不支持应用窗口模式，则使用默认浏览器打开。

操作
----
鼠标左键：翻开格子
鼠标右键：插旗或取消插旗
触屏：使用页面上的“翻开 / 插旗”模式后轻触格子
键盘：方向键移动，Enter 或空格翻开，F 插旗
顶部“↻”按钮：重新开始当前难度
简单：9 x 9，10 雷
困难：16 x 16，40 雷
噩梦：30 x 16，99 雷

说明
----
程序只在本机 127.0.0.1 上临时提供游戏文件，不访问外部网络。
游戏运行期间可以刷新页面，刷新后会开始新局。
要完全退出游戏，请关闭游戏窗口，并在任务栏或任务管理器中退出“扫雷.exe”。
Windows 首次运行自行生成的程序时可能显示安全提示，可选择“更多信息”后确认运行。

源码与重新构建
--------------
网页源码位于 app 文件夹，测试位于 tests 文件夹。
重新构建要求 Node.js 24。首次获取源码后运行：
  npm ci
之后可以运行：
  npm test
  npm run build

构建脚本会生成候选程序并完成本机资源健康检查；只有检查通过后才会替换现有“扫雷.exe”。
